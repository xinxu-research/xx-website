Accessibility

I have developed this website with accessibility in mind and will continue to improve it as content and features evolve.

Current approach

The website uses clear headings, readable colour contrast, descriptive page titles, and layouts designed to work across different devices. Reduced-motion preferences are supported where animations are used.

Feedback

If you encounter an accessibility barrier while using this website, please get in touch so that I can investigate and improve it. Thank you.
